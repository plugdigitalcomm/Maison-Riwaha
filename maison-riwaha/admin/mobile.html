Connexion

Connectez-vous avec votre compte GitHub pour gérer les parfums, le stock et les photos depuis votre téléphone.

Une fenêtre GitHub s'ouvre : acceptez, puis revenez ici. Sur ordinateur, l'admin complet permet aussi de modifier les avis, les réglages et les tarifs.

    Stock vide (∞) = non suivi, toujours disponible. 0 = rupture de stock.
    Admin complet (avis, réglages, tarifs), plus pratique sur ordinateur.
